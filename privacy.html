Приложение «ИБ: тренажёр билетов» · MoonGameTechnology · Обновлено 10 октября 2026 года

Учебные материалы

Тренажёр содержит базовые вопросы, сложные технические сценарии, задачи по защите ИИ и ситуации по MITRE ATT&CK, OWASP и CVE. «Все вопросы» и «Барабан тем» объединяют базовый банк, ИИ и ситуации; «Сеньор» доступен отдельно. Это материалы для самостоятельной подготовки, а не официальный экзамен или подтверждение квалификации. Дата проверки правовых вопросов указана в карточках.

Данные на устройстве

Ответы, результаты, ошибки, незавершённые попытки, выбранная и пройденные темы барабана и заметки к сценариям сохраняются только на вашем устройстве. Разработчик не получает эти данные. Они хранятся до сброса прогресса, очистки данных приложения или его удаления. У каждого банка и общего режима отдельный прогресс; кнопка «Сбросить прогресс» удаляет данные выбранного банка. Для удаления всех данных используйте настройки Android: Приложения → ИБ: тренажёр билетов → Хранилище → Очистить данные.

Android-приложение

Все учебные разделы включены в Android-приложение и работают без интернета. Приложение не запрашивает разрешений Android, не содержит рекламы, аналитики, покупок, подписок или регистрации. Автоматическое облачное резервное копирование и перенос данных приложения отключены. Для работы нужен Android 8.0 или новее и Android System WebView версии 100 или новее.

Обратная связь

Обратная связь открывается на GitHub во внешнем браузере только по вашему действию. Для публикации нужен аккаунт GitHub; обращения публичны. Разработчик сможет прочитать опубликованное обращение. Не включайте личные или конфиденциальные сведения.

В версии Google Play текст обращения вы вводите непосредственно на GitHub в браузере. Приложение добавляет только общедоступные сведения о банке и вопросе, не получает текст обращения и не имеет доступа к вашему аккаунту GitHub. В веб-версии и версии RuStore можно предварительно написать сообщение в форме: черновик хранится в памяти до закрытия или перезагрузки страницы. Перед переходом виден полный текст, включающий сообщение, банк, версию и содержание вопроса. Ответы, статистика и личные заметки не добавляются.

Опубликованный текст хранится GitHub по его правилам. Вы можете отредактировать или удалить свой комментарий средствами GitHub. Для просьбы удалить обращение свяжитесь с разработчиком через обращения проекта; удаление публичного обращения не удаляет локальный прогресс. Используя «Скопировать текст», вы сами выбираете, передавать ли его кому-либо.

Внешние сайты и веб-версия

Учебные источники и GitHub открываются в браузере по вашему выбору и обрабатывают данные по собственным правилам. Политика конфиденциальности GitHub. Веб-версию размещает GitHub Pages; для загрузки сайта нужен интернет, и хостинг обрабатывает технические данные соединения согласно своим правилам. Данные веб-версии и Android-приложения хранятся отдельно и не синхронизируются.
