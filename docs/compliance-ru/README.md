## Состав и поведение

Кнопка **«Комплаенс РФ»** открывает отдельную страницу `compliance.html`: **15 тем, по 12 вопросов — всего 180**. Исходные 120 пунктов сохранены; добавлено по четыре авторские задачи на модуль. Пять существующих вопросов используются с прежними ID, остальные 175 добавлены пакетом. GDPR остаётся в базовом разделе.

Внутри комплаенса доступны темы, смешанные билеты 20/50, все 180 вопросов, тренировка, экзамен и повторение ошибок. Прогресс отдельный. Общий режим включает **1151 вопрос**: базовые **895 / 44 темы**, комплаенс **180 / 15 тем**, ИИ **40 / 4 темы**, ситуации **36 / 3 темы**. Барабан содержит **66 тем**. Со «Сеньором» (ещё 60) всего **1211 самостоятельных вопросов**.

Рядом с темами расположена ссылка на отдельную страницу материалов: **15 практических кейсов**, их ориентиры и критерии самопроверки, **34 карточки источников ответов** и **10 дополнительных точек поиска вопросов**. Кейсы не превращены в тесты с единственным ответом и не прибавлены к числу вопросов. Ответы практикума раскрываются отдельно от условий. Автоматической оценки свободного текста и обязательного поля «мои размышления» нет.

Правовые ссылки и разбор вариантов открываются только после проверки ответа или завершения экзамена. В обычной тренировке дополнительно видны проверяемое знание и пример доказательства выполнения. Рекомендованные практики помечены отдельно от применения нормы. Двадцать дополнительных понятий используют ту же синюю подчёркнутую справку, что и общий словарь: ИСПДн, ГИС, КИИ, ГосСОПКА, комплаенс, аттестация, аккредитация и другие. Чтение справки не выбирает ответ и не меняет статистику.

## Хранение и загрузка

При интеграции комплаенса в `questions.json` было 840 вопросов. После [расширения OSI](../osi-protocols-review.md) этот файл содержит 900 вопросов; комплаенс по-прежнему подключается отдельно. Пакет находится в `data/compliance-ru/`: манифест, 15 файлов модулей по 12 исследовательских пунктов и практикум. Общий загрузчик `basic-bank.js` собирает композицию из 1075 вопросов. `selectSection` без изменения исходных объектов выбирает 895 базовых или 180 вопросов комплаенса; в комплаенсе название модуля становится темой. `all-questions.js` использует полную композицию для общего режима и 15 отдельных групп комплаенса в барабане.

Новые ID вычисляются детерминированно: `rfc001` → `q10001`, …, `rfc180` → `q10180`, кроме пяти явно сопоставленных пунктов. Неиспользованные позиции этих пяти ID не заполняются. Их резервирование предотвращает изменение ID при редактуре или переносе между файлами. Загрузчик проверяет конфликты, источники, число модулей, варианты и карту повторного использования. Если отсутствует или повреждена любая часть пакета, неполный базовый банк не запускается. Повторная попытка загружает все части заново.

Манифест и разделы — канонический источник расширения. Не следует редактировать производную копию объединённого банка отдельно. Исходные варианты пяти заменённых исследовательских пунктов сохранены в пакете для происхождения данных, но **не добавляются вторыми вопросами в работающий набор**.

Текст, варианты и объяснения этих вопросов сохранены; изменяется принадлежность к теме и добавляются ссылки на нормы и сведения о модуле. Повторной самостоятельной записи того же вопроса в общем билете и барабане нет.

При первой интеграции для отбора использован снимок четырёх банков — 976 исходных заданий — и поиск похожих формулировок с ручной проверкой сильных совпадений. Отсутствие точных повторов проверяется тестом. Это не независимая экспертиза всех смысловых пересечений: базовое правило и сценарий с дополнительными условиями могут намеренно соседствовать. Старый отчёт описывает прежний, более узкий охват исследования; этот документ фиксирует именно интеграционную проверку.

## Правовой статус и дополнительные источники

Дата исходной сверки норм — **10.10.2026**. Это учебный материал, не индивидуальное юридическое заключение и не официальная программа экзамена. Независимое юридическое ревью не проводилось. У источников сохранены тип, прочитанные положения и ограничения копии. Методические рекомендации и предлагаемые практики не объявляются всеобщей юридической обязанностью.

Поправки с отложенным вступлением не представлены как действующие: в частности, для пункта 7 приложения к приказу ФСТЭК №137 сохранена дата 01.03.2027, отдельно от общего вступления других изменений 01.09.2026. Первоисточники/копии нормы указаны у соответствующих вопросов и в манифесте; дату реальной применимости необходимо пересматривать при обновлении пакета.

Десять дополнительных ссылок на ТГУ, ИрГУПС, Huntflow, Право.ru, Банк России, RTM, Kaspersky ICS CERT, ФНС и Роскомнадзор находятся в отдельном разделе. **Все их вопросы не импортированы и не объявлены проверенными.** Для старых материалов указана необходимость обновления норм; для закрытых и нераскрывшихся интерактивных частей — предел доступного содержания. Идею будущей задачи нужно отделять от источника правильного ответа.

## Сохранения и поставка

ID существующих вопросов не меняются. При изменении состава сохраняются общая статистика и допустимые ID ошибок; незавершённые попытки и прежняя раскладка билетов сбрасываются по существующему правилу приложения. У барабана изменение сигнатуры также сбрасывает старую попытку и закрытые темы с уведомлением. При выделении раздела ошибки по его ID однократно копируются из старого базового сохранения в `cs-bilets-ru.compliance.v1`; запись назначения выполняется до отметки переноса. Если она не удалась, старое сохранение не перезаписывается. Накопленные общие счётчики остаются в базовом разделе: исходный формат не хранит их распределение по вопросам. Новые счётчики комплаенса начинаются с нуля; сброс действует только внутри открытого раздела.

Pages копирует новые JS/HTML и каталог данных. Android включает те же файлы офлайн; WebView разрешает только конкретные перечисленные пути, а не произвольный доступ к каталогу. Внешние сайты источников для чтения требуют сети и открываются по прежним правилам во внешнем браузере. Разрешения Android, аналитика, платёжные функции и ключ подписи не меняются.

## Проверки

```bash
node tests/check-compliance.cjs
node tests/check-glossary.cjs
node tests/check-trainer.cjs
node tests/check-case-trainer.cjs
node tests/check-scenarios.cjs
node tests/check-all-questions.cjs
node tests/check-topic-wheel.cjs
node tests/check-wheel-visual.cjs
```

Новая проверка охватывает состав темы, пять повторно используемых ID, неизменность остальных исходных вопросов и GDPR, ссылки и юридические метаданные, отсутствие точных повторов, целостную загрузку и повторную попытку, реальное объединение для общего билета/барабана, экранирование справки и комплект файлов Android/Pages. Существующие проверки режимов используют итоговую композицию. Это технические проверки, не доказательство юридической правильности всех ответов.
