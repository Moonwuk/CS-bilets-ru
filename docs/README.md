## Поддержка документации

Новый обзор следует добавлять в этот указатель и связывать с исходными банками и связанными документами.
Для датированного исследования указываются дата, commit SHA, фактический охват и ограничения.
Канонический источник вопросов и ответов — JSON-банки репозитория; документация описывает методику и результаты,
но не создаёт отдельный редактируемый банк и не подменяет техническую проверку ответов.
