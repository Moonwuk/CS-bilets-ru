## P01 · P1 · Ревью кода → исправление → тест

**Направление:** AppSec. **Формат:** Практикум.

**Существующие ID:** `q189,q199,q201,q361,q374,q376,s029`.

**Почему это не дубль:** Не новый словарь уязвимостей, а самостоятельный результат без вариантов ответа.

**Самостоятельное задание:** Дать 30–60 строк учебного кода, описать нарушенную границу доверия, исправить и написать отрицательный тест.

**Основание:** S05,S10,S13. [Источник идеи](https://github.com/jassics/security-interview-questions/blob/main/application-security-interview-questions.md).

## Критерии готовности будущего задания

Для каждого направления до реализации следует подтвердить новое проверяемое знание,
сверить правильный разбор с первичным источником и проверить отсутствие дубля по существующим ID.
Для практикума нужен воспроизводимый результат, для теста — достаточные условия и разбор всех вариантов,
для устного формата — критерии самостоятельной оценки. Эти проверки не заменяются статусом приоритета.
