# Поддержка проекта: состояние интеграции

Экран поддержки подготовлен: тихая ссылка в меню, 50/100/200 ₽ и своё целое число от 50 ₽. Это пока не рабочая платёжная интеграция. Checkout отключён явно; приложение не запрашивает банковские данные и не изображает успешную оплату.

## Что необходимо для продолжения

- Публичный consoleApplicationId приложения из RuStore Консоли.
- Подключённая монетизация и доступный потребляемый товар: productId, цена и валюта, статус модерации.
- Подтверждение RuStore, что выбранный товар допускается как добровольная поддержка без закрытия функций.
- Для ввода любой суммы нужна подтверждённая модель цены и количества. В Pay SDK параметр quantity применяется к потребляемым товарам, произвольной цены в ProductPurchaseParams нет. Нельзя молча округлять введённую сумму или создавать несколько списаний.

Секретные API-ключи и ключ подписи не отправлять в чат и не размещать в JS/APK.

## Оставшаяся реализация

Текущая Android-сборка напрямую вызывает javac/aapt2/d8 без менеджера зависимостей. Для Pay SDK требуется сборка с разрешением Android-зависимостей (например Gradle), инициализация SDK, возврат из платежа по deeplink и строго ограниченный native bridge. До подтверждённой конфигурации это не реализовано.

Перед оплатой получать актуальную цену из RuStore и сверять итог с выбранной суммой. Отображать успешную поддержку только после подтверждённого статуса платежа; обрабатывать отмену, незавершённый платёж, повторное нажатие, перезапуск и тестовый режим. Проверить реальную sandbox-покупку на Android. Для GitHub Pages отдельно выбрать поддерживаемый web checkout; Android SDK в браузере не работает.
