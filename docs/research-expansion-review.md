# Расширение по исследованию собеседований — 10 октября 2026

[Документация](README.md) · [Практикум с исходными данными](research-expansion-practice.md)

Добавлены **100 авторских вопросов q741–q840** по направлениям [исследования от 7 октября](interview-bank-comparison-2026-10-07.md) и предложениям по углублению инструментального блока. Это новое наполнение на основе приоритетов, а не повторный импорт уже добавленных 140 вопросов JWT/OWASP. Формулировки и варианты ответов написаны для тренажёра; технические положения сверены с первичными источниками. У каждого вопроса сохранены учебная цель, дата проверки, источники и ID доступных подсказок.

## Проверка повторов и содержания

Сопоставлены тексты и учебные цели с существующим банком; кандидаты с наибольшей лексической близостью просмотрены вручную. При подготовке заменены повторы существующих заданий про PID/ProcessGuid (q252), прямой расчёт precision/recall (q257–q258), подписанную системную утилиту (q255), порядок ACL (q140), аргументы subprocess (q361) и хранение журналов (q260). Новые варианты проверяют соответственно DNS-кеш, несбалансированную выборку и выбор порога, сохранённый канал EDR, области сетевых правил, тайм-аут процесса и запаздывающую доставку.

Отдельно q671 перестал повторять q023: теперь он проверяет повторную аутентификацию перед изменением почты восстановления. В q023 уточнено, что авторизация возможна и для анонимного субъекта по политике. Постоянные ID сохранены.

Правильные позиции нового пакета распределены поровну: по 25 на каждую позицию. Каждый из 400 вариантов имеет собственное пояснение. Поиск похожих формулировок помогает редактору, но не является доказательством отсутствия всех смысловых повторов в историческом банке.

Для почты используется [RFC 9989](https://www.rfc-editor.org/rfc/rfc9989.html), опубликованный в мае 2026 года вместо RFC 7489/9091. Поведение конкретных продуктов явно названо в вопросе; оно не переносится на любой продукт того же класса. Полные ссылки находятся в `questions.json` → `sources`, связь — в `sourceIds`.

## Совместимость и проверка

Состав и подпись банка меняются. Существующая миграция сохраняет накопленные результаты и известные ID ошибок, но сбрасывает незавершённую попытку и результаты старой раскладки билетов. Это предотвращает продолжение попытки с устаревшими вариантами. Для перехода с 740 вопросов добавлен отдельный сценарий миграции. Внутренняя раскладка теперь 16 × 50 + 40; старые нумерованные билеты в меню не возвращаются.

Автоматические проверки охватывают структуру и источники пакета, достижимость всех его подсказок до ответа, безопасную разметку, миграцию, тренировку, экзамен, полный общий билет и завершение всех 51 тем барабана. Геометрия колеса проверяется на 51 секторе. Android и Pages используют тот же банк и словарь. Практикум находится в документации репозитория; отдельный режим выполнения кода в приложении не добавлялся.
