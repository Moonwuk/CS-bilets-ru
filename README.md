# Тренажёр билетов по информационной безопасности

Простой сайт для подготовки к собеседованиям по ИБ методом проб и ошибок. Сайт работает полностью в браузере и подходит для GitHub Pages.

## Возможности

- 400 вопросов по 22 темам, включая отдельный раздел «Модель OSI» из 41 вопроса.
- 8 билетов по 50 вопросов с равномерным распределением тем; в каждом 5–6 вопросов по OSI.
- Случайный билет из 50 вопросов и подборки по темам.
- Тренировка с пояснением после каждого ответа.
- Экзамен с проверкой и разбором после завершения.
- Повторение ошибочных и пропущенных вопросов.
- Перемешивание вопросов и вариантов ответов.
- Уровни сложности, метки сертификаций и вопросов по темам собеседований.
- Технические источники и открытые интервью-подборки в разборе ответа.
- Автоматическое сохранение результатов, ошибок и незавершённого билета.
- Продолжение билета после перезагрузки или возвращения в меню.
- Сброс прогресса с подтверждением.
- Интерфейс для компьютера и телефона.

При изменении состава вопросов, их ответов или раскладки билетов общая статистика и ошибки по существующим вопросам сохраняются. Незавершённый сеанс и результаты прежних билетов сбрасываются, чтобы старый результат не относился к другому набору заданий.

Прогресс хранится в `localStorage` этого браузера на этом адресе сайта. Перезагрузка и закрытие страницы его не сбрасывают. Между устройствами и браузерами прогресс не синхронизируется. Очистка данных сайта удаляет сохранения; в приватном режиме они могут исчезнуть после закрытия приватного окна. Если браузер запрещает сохранение, тренажёр продолжит работать и покажет уведомление.

## GitHub Pages

1. Откройте [Settings → Pages](https://github.com/Moonwuk/CS-bilets-ru/settings/pages).
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. Выберите ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Дождитесь завершения публикации. GitHub покажет адрес сайта на этой же странице.

Ожидаемый адрес после включения Pages: <https://moonwuk.github.io/CS-bilets-ru/>.

При следующих изменениях в `main` GitHub Pages обновит сайт автоматически. Файл `.nojekyll` отключает обработку Jekyll. Все пути к CSS, JavaScript и банку вопросов относительные, поэтому сайт работает в подкаталоге репозитория.

Исходная версия тренажёра: <https://infosec-study-tickets.mazujlava.chatgpt.site>. Это другой адрес, поэтому его сохранения не переходят на GitHub Pages.

## Запуск

Сайт написан на HTML, CSS и JavaScript. Установка пакетов и сборка не нужны.

Из корня репозитория запустите локальный HTTP-сервер:

```bash
python3 -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000). Для Windows можно использовать `py -m http.server 8000`.

Сайт загружает банк вопросов через `fetch`, поэтому запускать его следует через HTTP-сервер.

| Файл | Назначение |

| `index.html` | Разметка интерфейса |

| `tests/check-trainer.cjs` | Проверка режимов, результатов и сохранения прогресса |

## Проверка

Проверки не требуют установки зависимостей. Нужен Node.js:

```bash
node tests/check-trainer.cjs
```

Проверяются подсчёт результатов, перемешивание ответов, повторение ошибок, скрытие подсказок в экзамене, восстановление незавершённого билета и работа при недоступном хранилище.

## Банк вопросов

Банк включает 88 вопросов из `infosec_interview.docx` и 312 авторских вопросов по открытым программам сертификаций, темам собеседований и технической документации. В 53 исходных вопросах уточнены формулировки и пояснения.

Раздел «Модель OSI» содержит вводный вопрос и 40 новых заданий: функции семи уровней, инкапсуляция, связь с TCP/IP, адресация, устройства и диагностика. У 81 вопроса есть метка «Собеседование»; темы взяты из девяти открытых подборок, а ответы проверены по техническим первоисточникам.

Каждый вопрос содержит уникальный `id`, тему `topic`, текст `question` и четыре варианта `options`. У одного варианта `correct: true`; каждый вариант имеет своё `explanation`. Новые вопросы дополнены полями `origin`, `difficulty`, `certifications`, `sourceIds` и, где применимо, `interviewSourceIds`. Общие каталоги материалов хранятся в `sources`, `certificationGuides` и `interviewCollections`. Ссылки показываются после проверки ответа или завершения экзамена.

Тренажёр помогает изучать материал и не является официальным экзаменом или банком вопросов какой-либо сертификации.
